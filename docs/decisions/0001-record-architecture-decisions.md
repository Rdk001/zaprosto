# ADR-0001: Вести журнал архитектурных решений

- Статус: Accepted
- Дата: 2026-08-26

## Контекст

Проект создаётся с нуля. Без краткой истории решений причины выбора технологий и ограничений быстро теряются.

## Решение

Фиксировать значимые, долгосрочные или труднообратимые технические решения в виде ADR в каталоге `docs/decisions/`.

## Последствия

- Решения получают явный контекст и обоснование.
- Изменение принятого решения оформляется новым ADR, который ссылается на заменяемый документ.
- Поддержание записей требует небольшой дополнительной дисциплины.
