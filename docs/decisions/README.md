# Архитектурные решения

Здесь хранятся Architecture Decision Records (ADR) — краткие записи о значимых технических решениях.

## Именование

Используйте последовательный номер и короткое название:

```text
0002-choose-application-stack.md
```

## Шаблон

```markdown
# ADR-NNNN: Название

- Статус: Proposed | Accepted | Superseded | Deprecated
- Дата: YYYY-MM-DD

## Контекст

## Решение

## Последствия
```
