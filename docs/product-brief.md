# Краткое описание продукта

## Продукт и цель

«Запросто» / Zaprosto — русскоязычная система онлайн-записи для барбершопа. Практичный MVP должен демонстрировать полноценный бизнес-сценарий в портфолио и позволять адаптацию для продажи российскому малому бизнесу, в том числе через Kwork, без платных подписок на старте.

## Пользователи

### Клиент

Выбирает услугу, конкретного мастера или «Любого мастера», дату и доступное время, указывает имя и телефон и получает подтверждение записи. Telegram подключается добровольно для получения уведомлений. Email не собирается.

Клиент может отменить запись по защищённой ссылке. Самостоятельного переноса в MVP нет: для изменения времени клиент отменяет прежнюю запись и создаёт новую.

### Администратор

Настраивает услуги и мастеров, назначает каждому мастеру доступные услуги, управляет рабочими графиками, перерывами, выходными и записями. Цена и длительность услуги общие для всех мастеров.

Администратор может вручную создавать записи, редактировать услугу, мастера, дату, время, имя и телефон клиента, отменять и переносить записи, а также отмечать результат визита как «Выполнена» или «Клиент не пришёл». Ручная запись сразу блокирует слот.

## Границы подтверждённого MVP

- Одна установка обслуживает один барбершоп и один филиал.
- Для каждого покупателя разворачивается отдельный экземпляр.
- Публичный mobile-first сценарий записи на русском языке.
- Управление услугами, мастерами, расписанием и записями.
- Расчёт доступных окон и запрет пересечений.
- Настраиваемый горизонт бронирования от 7 до 90 дней, по умолчанию 30 дней.
- Выбор конкретного мастера или варианта «Любой мастер».
- Предложение только тех мастеров, которым назначена выбранная услуга.
- Учёт телефонных и офлайн-записей, вручную созданных администратором.
- Самостоятельная отмена клиентом по защищённой ссылке.
- Сохранение отменённых записей и истории изменений статуса.
- Подтверждение записи и согласованные Telegram-уведомления.
- Настраиваемый часовой пояс бизнеса, по умолчанию `Europe/Moscow`.

## Уведомления

- Клиент получает подтверждение сразу после создания записи.
- При добровольном подключении Telegram клиент получает одно напоминание за 2 часа до визита.
- Для записи, созданной менее чем за 2 часа до начала, отдельное напоминание не отправляется.
- Администратор получает Telegram-уведомления о новой записи и отмене.
- При отмене, переносе или изменении услуги, мастера, даты либо времени администратором клиент получает Telegram-уведомление, только если Telegram подключён.
- Если Telegram не подключён, автоматического уведомления нет: администратор связывается с клиентом по телефону.
- Исправление имени или телефона автоматического уведомления не вызывает.
- Для ручной записи интерфейс показывает готовый текст подтверждения и защищённую ссылку, которые администратор может отправить клиенту вручную. По одному номеру телефона автоматически написать в Telegram нельзя.
- Клиент может подключить Telegram по защищённой ссылке; после подключения действует общее правило напоминания за 2 часа.
- SMS не используется, поскольку на старте разрешены только бесплатные сервисы.

## Состояния записи

- Новая запись получает статус «Запланирована».
- Из «Запланирована» запись переходит в «Выполнена», «Клиент не пришёл» или «Отменена».
- «Выполнена» и «Клиент не пришёл» можно взаимно менять для исправления ошибки, но устанавливать эти статусы можно только после начала визита.
- Отменённая запись не восстанавливается; при необходимости создаётся новая.
- Перенос и редактирование времени разрешены только для запланированной записи.
- Каждое изменение статуса сохраняется в истории.

Отмена не удаляет запись: статус меняется на «Отменена», слот освобождается, а инициатор, время, исходные данные и необязательная причина отмены сохраняются. Отменённые записи по умолчанию скрыты из активного расписания и доступны через историю или фильтр.

## Ограничения

- Только бесплатные сервисы и бесплатные тарифы на старте.
- Практичность и простота важнее преждевременного масштабирования.
- Мультифилиальность и многопользовательский SaaS не входят в MVP.
- Утверждён модульный Next.js-монолит с PostgreSQL и отдельным worker-процессом для фоновых Telegram-уведомлений; подробности зафиксированы в ADR-0002.

## Распределение «Любого мастера»

Среди свободных мастеров с назначенной услугой система последовательно выбирает мастера с наименьшим количеством забронированных минут за выбранный день, затем с меньшим количеством записей, а при полном равенстве — стоящего раньше в порядке, установленном администратором.

## Телефон клиента

Принимаются российские номера с префиксом `+7` или `8`. Пробелы, скобки и дефисы во вводе допустимы. Номер без префикса или номер другой страны отклоняется. Перед сохранением номер приводится к формату `+7XXXXXXXXXX`.
